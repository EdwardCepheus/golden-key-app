# 金钥匙 × WorkBuddy AI 数据分析使用指南

## 🎯 功能概述

金钥匙集成了 WorkBuddy AI 分析功能，可以将商品数据一键导出并发送给 WorkBuddy 进行智能分析。

## 📋 使用步骤

### 1️⃣ 打开分析窗口
- 在金钥匙顶部工具栏找到 **"AI 分析"** 按钮（带有 ✨ 特效的按钮）
- 点击打开分析配置窗口

### 2️⃣ 选择分析范围
- **已选商品**: 如果你已经通过复选框选择了部分商品，只分析这些商品
- **全部商品**: 如果没有选择任何商品，则分析全部商品

### 3️⃣ 选择分析类型
| 类型 | 说明 |
|------|------|
| 📊 全面分析 | 综合所有维度，给出完整报告 |
| 💰 利润分析 | 深度分析利润结构和优化空间 |
| 📈 趋势分析 | 分析销量趋势，预测未来走向 |
| ⚖️ 竞品分析 | 对标竞争对手，分析竞争优势 |
| 🔍 异常检测 | 发现数据中的异常和潜在问题 |

### 4️⃣ 一键复制
- 点击 **"复制并分析"** 按钮
- 数据会自动复制到剪贴板
- 会显示复制成功提示

### 5️⃣ 粘贴到 WorkBuddy
- 打开 WorkBuddy 对话窗口
- 粘贴（Ctrl/Cmd + V）刚才复制的内容
- WorkBuddy 会自动分析数据并返回结果

## 📝 分析内容示例

复制到 WorkBuddy 的数据格式如下：

```markdown
# 🛒 销售数据分析请求

## 📊 数据概览
📊 **数据概览**
- 商品总数: **10** 个
- 有定价商品: **8** 个
- 覆盖品类: **5** 个
...

## 📋 商品数据
| 商品名称 | 品类 | 成本 | 售价 | 利润 | 利润率 | 标签 |
|----------|------|------|------|------|--------|------|
...

## 🎯 请帮我完成以下分析
1️⃣ 产品排名分析
2️⃣ 趋势分析
...
```

## 💡 分析维度

根据选择的分析类型，WorkBuddy 会提供以下分析：

### 📊 全面分析
- 商品覆盖率
- 标签分析
- 标题优化建议
- 描述优化建议
- 商品分层（核心/潜力/待优化）

### 💰 利润分析
- 利润分层（高/中/低/亏损）
- 成本结构分析
- 定价策略建议
- 利润预测

### 📈 趋势分析
- TOP 产品排名
- 销量趋势识别
- 异常数据检测
- 选品建议

### ⚖️ 竞品分析
- 价格竞争力
- 差异化卖点
- 目标客户画像
- 竞争优势提炼

## ⚠️ 注意事项

1. **商品数量限制**: 建议一次分析不超过 100 个商品，数据量过大会影响分析质量
2. **数据完整性**: 确保商品有定价信息，否则利润分析可能不准确
3. **网络要求**: 需要网络连接才能使用 WorkBuddy
4. **隐私安全**: 所有数据都在本地处理，不会上传到第三方服务器

## 🔧 高级用法

### 自定义问题
在分析窗口中，可以添加自定义问题，WorkBuddy 会针对性地回答：

示例：
- "哪些商品利润率最高？"
- "下个月应该主推哪些商品？"
- "哪些商品需要调整定价？"

### 导出格式
支持多种数据导出格式：
- **Markdown**: 默认格式，适合直接粘贴到 WorkBuddy
- **JSON**: 机器可读格式，可用于其他工具
- **CSV**: Excel 兼容格式

## 📞 反馈与支持

如果分析结果不符合预期，可以通过以下方式优化：

1. **增加商品信息**: 标题、描述越详细，分析越准确
2. **选择合适的分析类型**: 不同场景选择不同的分析维度
3. **分批分析**: 大数据量时分批分析效果更好
